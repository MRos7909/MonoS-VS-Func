# VS-MFunc

Script with some useful Vapoursynth functions

## Installation

``` sh
export PIP_EXTRA_INDEX_URL="https://pypi.nvidia.com/ https://jaded-encoding-thaumaturgy.github.io/vs-wheels/simple"

curl https://github.com/WolframRhodium/muvsfunc/blob/master/muvsfunc.py $SITE_PACKAGES_PATH/muvsfunc.py

pip install git+https://github.com/MonoS/MonoS-VS-Func.git
```
